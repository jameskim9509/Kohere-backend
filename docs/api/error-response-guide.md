# Error Response Guide

> 이 문서는 템플릿입니다. 에러 처리 표준이 정해지면 각 섹션을 채웁니다.
> 관련 문서: [api-design-guide](./api-design-guide.md)

## 목적

> (작성) 표준 에러 응답·처리 전략의 목적을 적는다.

## 1. 표준 에러 응답 스키마

> (작성) 모든 에러가 공유할 응답 JSON 구조와 필드 정의를 적는다.

## 2. 예외 분류

> (작성) 도메인/검증/인증·인가/시스템 등 예외 분류 기준을 적는다.

## 3. HTTP Status 매핑

> (작성) status별 사용 시점과 대표 코드를 적는다.

## 4. 에러 코드 카탈로그

> (작성) 공통/도메인 에러 코드를 한 곳에 등록한다.

## 5. 예외 계층 / 전역 핸들러

> (작성) 예외 계층 구조와 전역 핸들러 변환 원칙을 적는다.

## 6. 로깅 / 재시도 정책

> (작성) 분류별 로그 레벨과 재시도 가능 여부를 적는다.

## 7. 클라이언트 처리 가이드

> (작성) 클라이언트의 status/code 분기 처리 방법을 적는다.

## 체크리스트

> (작성) 에러 처리 규칙 준수를 확인할 항목을 적는다.
