# Migration Policy

> 이 문서는 템플릿입니다. 마이그레이션 도구가 정해지면 각 섹션을 채웁니다.

## 목적

> (작성) 스키마 변경을 버전 관리·재현 가능하게 한다는 목적을 적는다.

## 1. 기본 규칙

> (작성) 마이그레이션 파일 작성·불변·forward-only 등 기본 규칙을 적는다.

## 2. 파일 네이밍 & 배치

> (작성) 도구별 파일 네이밍 규칙과 위치를 적는다.

## 3. 되돌릴 수 있는 변경

> (작성) 변경 유형별 되돌리기 난이도와 안전한 접근을 적는다.

## 4. NOT NULL 컬럼 추가 절차

> (작성) 기존 데이터 호환을 위한 단계적 절차를 적는다.

## 5. Expand-Contract 패턴

> (작성) 무중단 배포를 위한 확장 → 이행 → 축소 절차를 적는다.

## 6. 인덱스 추가 시 락 주의

> (작성) 큰 테이블 인덱스 추가 시 락 최소화 방법을 적는다.

## 7. 리뷰 & 배포 흐름

> (작성) 작성 → 로컬 → PR → CI → 배포 → 검증 흐름을 적는다.

## 체크리스트

> (작성) 마이그레이션 PR에서 확인할 항목을 적는다.
