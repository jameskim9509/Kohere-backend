# Database Design

> 이 문서는 템플릿입니다. DB가 정해지면 각 섹션을 채웁니다.

## 목적

> (작성) 명명 규칙·공통 컬럼·인덱스/제약 가이드를 제공한다는 목적을 적는다.

## 1. 명명 규칙 (Naming Convention)

> (작성) 테이블·컬럼·키·인덱스·제약 명명 규칙을 적는다.

## 2. 공통 컬럼 표준

> (작성) 모든 테이블이 가질 공통 컬럼(생성/수정 시각 등)을 적는다.

## 3. ERD

> (작성) 도메인 ERD(ASCII 또는 Mermaid)를 그린다.

## 4. 테이블 DDL

> (작성) 신규 테이블 DDL 템플릿과 실제 스키마를 적는다. ([migration-policy](./migration-policy.md))

## 5. 데이터 타입 가이드

> (작성) 용도별 권장 타입을 적는다.

## 6. 인덱스 가이드

> (작성) 인덱스 설계 원칙을 적는다.

## 7. 제약과 무결성

> (작성) NOT NULL·외래 키·삭제 정책·CHECK 제약 규칙을 적는다.

## 체크리스트

> (작성) 테이블/컬럼 추가 시 확인할 항목을 적는다.
