# Code Style Convention

> 이 문서는 템플릿입니다. 언어/프레임워크가 정해지면 각 섹션을 채웁니다.

## 목적

> (작성) 코드 스타일 통일의 목적을 적는다.

## 1. 포맷팅 / 자동화 도구

> (작성) 포맷터·린터·정적 분석 도구와 CI 적용 방식을 적는다. (현재 CI는 [.editorconfig](../../.editorconfig) 준수만 검사)

## 2. 네이밍 규칙

> (작성) 클래스·메서드·변수·상수·테스트 이름 규칙을 적는다.

## 3. 계층 / 패키지 구조

> (작성) 계층 분리와 의존 방향, 패키지 구성 규칙을 적는다.

## 4. null / 매직 넘버 / 상태 표현

> (작성) null 처리·상수화·enum 사용 규칙을 적는다.

## 5. 예외 처리

> (작성) 예외 네이밍·메시지·전역 처리 규칙을 적는다.

## 6. 주석 / 함수 책임

> (작성) 주석 기준과 함수 단일 책임 원칙을 적는다.

## 체크리스트

> (작성) 코드 스타일 준수를 확인할 항목을 적는다.
