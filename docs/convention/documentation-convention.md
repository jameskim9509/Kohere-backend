# Documentation Convention

> 이 문서는 템플릿입니다. 문서 작성 규칙이 정해지면 각 섹션을 채웁니다.

## 목적

> (작성) 문서 작성 규칙의 목적을 적는다.

## 1. 문서 위치 규칙

> (작성) 문서 종류별 위치(`docs/`, `docs/adr/` 등)를 적는다.

## 2. 마크다운 스타일 규칙

> (작성) 제목·파일명·링크·코드블록 등 마크다운 작성 규칙을 적는다.

## 3. 코드 주석 / 문서 주석 규칙

> (작성) 언어별 문서 주석 형식과 주석 작성 기준을 적는다.

## 4. ADR 작성 시점

> (작성) 어떤 결정을 ADR로 남길지 기준을 적는다. ([docs/adr](../adr/README.md))

## 5. 문서 최신성 유지

> (작성) 코드/정책 변경 시 문서 갱신 규칙을 적는다.

## 체크리스트

> (작성) 문서 규칙 준수를 확인할 항목을 적는다.
