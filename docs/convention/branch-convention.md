# Branch Convention

> 이 문서는 템플릿입니다. 팀 브랜치 규칙이 정해지면 각 섹션을 채웁니다.
> 연계 문서: [commit-convention](./commit-convention.md), [pr-convention](./pr-convention.md), [collaboration-convention](./collaboration-convention.md)

## 목적

> (작성) 브랜치 규칙의 목적을 적는다.

## 1. 브랜치 네이밍 규칙

> (작성) 브랜치명 형식(예: `<type>/<설명>`)과 대소문자·구분자 규칙을 적는다.

## 2. type 목록

> (작성) 사용할 브랜치 type과 용도를 표로 정한다.

## 3. 기준 브랜치 (Base Branches)

> (작성) main/develop 등 보호 대상 기준 브랜치와 보호 규칙을 적는다. 전체 협업 흐름은 [collaboration-convention](./collaboration-convention.md) 참고.

## 4. 머지 전략

> (작성) Squash/Rebase/Merge commit 중 기본 전략과 사용 시점을 적는다.

## 5. 수명 주기 (Lifecycle)

> (작성) 브랜치 생성 → 작업 → PR → 머지 → 삭제 흐름을 적는다.

## 체크리스트

> (작성) 브랜치 규칙 준수를 확인할 항목을 적는다.
