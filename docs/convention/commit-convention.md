# Commit Convention

> 이 문서는 템플릿입니다. 커밋 규칙이 정해지면 각 섹션을 채웁니다.
> 연계 문서: [branch-convention](./branch-convention.md), [pr-convention](./pr-convention.md)

## 목적

> (작성) 커밋 메시지 규칙의 목적을 적는다.

## 1. 기본 형식

> (작성) 커밋 메시지 형식(예: `<type>(<scope>): <subject>`)과 각 요소 규칙을 적는다.

## 2. type 목록

> (작성) 사용할 커밋 type과 용도를 표로 정한다.

## 3. 예시

> (작성) 형식을 따른 커밋 메시지 예시를 적는다.

## 4. BREAKING CHANGE 표기

> (작성) 호환 불가 변경 표기 방법을 적는다.

## 5. 커밋 단위

> (작성) 좋은 커밋 단위 기준을 적는다.

## 체크리스트

> (작성) 커밋 규칙 준수를 확인할 항목을 적는다.
