# Pull Request Convention

> 이 문서는 템플릿입니다. PR 규칙이 정해지면 각 섹션을 채웁니다.
> 연계 문서: [branch-convention](./branch-convention.md), [commit-convention](./commit-convention.md), [collaboration-convention](./collaboration-convention.md)
> 템플릿: [.github/PULL_REQUEST_TEMPLATE.md](../../.github/PULL_REQUEST_TEMPLATE.md) · 코드 소유자: [.github/CODEOWNERS](../../.github/CODEOWNERS)

## 목적

> (작성) PR 규칙의 목적을 적는다.

## 1. PR 제목 형식

> (작성) PR 제목 형식([commit-convention](./commit-convention.md) 연계)을 적는다.

## 2. PR 본문 형식

> (작성) PR 본문 구성([PULL_REQUEST_TEMPLATE.md](../../.github/PULL_REQUEST_TEMPLATE.md) 기반)을 적는다.

## 3. PR 크기 가이드

> (작성) 권장 PR 크기와 분할 기준을 적는다.

## 4. 리뷰어 지정

> (작성) 리뷰어 지정·최소 승인 수 규칙을 적는다. ([CODEOWNERS](../../.github/CODEOWNERS))

## 5. 리뷰 진행 규칙

> (작성) 리뷰 코멘트·응답 규칙을 적는다.

## 6. 머지 조건 (Merge Gate)

> (작성) 머지 전 충족할 조건을 적는다. GitHub Ruleset 설정은 [collaboration-convention](./collaboration-convention.md) 참고.

## 체크리스트

> (작성) PR 규칙 준수를 확인할 항목을 적는다.
