# Project Brief

## 목적

이 문서는 프로젝트의 "왜/무엇을/어디까지"를 한 페이지로 정리한다.
신규 합류자, 이해관계자, AI 에이전트가 의사결정의 기준선을 빠르게 잡도록 돕는다.

> 예시(Spring Boot 기준): 아래 내용은 가상의 도메인 **"모임/일정 공유 서비스(Meetup)"** 를 예시로 작성했다.
> 실제 도메인/지표/일정은 프로젝트 확정 후 교체한다. 스택은 예시이며, 실제 값은 [tech-stack.md](../../.claude/rules/tech-stack.md)에서 확정한다.

---

## 1. 한 줄 요약 (Elevator Pitch)

> "소규모 모임의 호스트가 일정을 만들고 초대코드로 참여자를 모아, 참석 여부와 일정 변경을 한곳에서 공유하는 서비스."

---

## 2. 배경 (Background / Problem)

- 소규모 모임 일정은 메신저 단체방에 흩어져 있어 누가 오는지 추적이 어렵다.
- 일정 변경이 생기면 공지가 묻히고, 참석/불참 집계를 사람이 수기로 센다.
- 외부 캘린더와 연동이 안 되어 일정 누락이 잦다.

→ 호스트 1명이 일정을 만들고, 참여자가 초대코드로 합류하여 참석 여부를 한 화면에서 관리하는 단일 진실 소스(Single Source of Truth)가 필요하다.

---

## 3. 목표 (Goals)

- 호스트가 3분 안에 모임과 첫 일정을 만들 수 있다.
- 참여자가 초대코드만으로 가입/참여할 수 있다(앱 설치 외 추가 절차 최소화).
- 일정 변경 시 참여자에게 즉시 알림이 전달된다.

---

## 4. 범위 (Scope)

### In scope (이번 범위에 포함)

| # | 항목 | 비고 |
| --- | --- | --- |
| 1 | 회원 가입/로그인 (JWT 기반) | [access-control](../security/access-control.md) 참고 |
| 2 | 모임(Meeting) 생성/수정/삭제 | 호스트 권한 |
| 3 | 초대코드 발급/참여 | 코드 만료/재발급 포함 |
| 4 | 일정(Event) 생성/변경 및 참석 여부(RSVP) 집계 | 참석/불참/미정 |
| 5 | 일정 변경 알림 (푸시/이메일) | 외부 연동, [external-integration](../architecture/external-integration.md) |

### Out of scope (이번 범위에서 제외)

| # | 항목 | 사유 / 향후 계획 |
| --- | --- | --- |
| 1 | 결제/정산 기능 | 1차 범위 아님, 차기 마일스톤 검토 |
| 2 | 실시간 채팅 | 외부 메신저로 대체, MVP 제외 |
| 3 | 다국어(i18n) | 초기엔 한국어만 지원 |
| 4 | 외부 캘린더 양방향 동기화 | 1차는 단방향(읽기) 내보내기까지만 검토 |

## 5. 핵심 기능 목록 (Key Features)

| 기능 | 설명 | 주요 액터 |
| --- | --- | --- |
| 인증 | 가입/로그인/토큰 재발급 | 사용자 |
| 모임 관리 | 모임 CRUD, 호스트 위임 | 호스트 |
| 초대 | 초대코드 발급/참여/만료 | 호스트, 참여자 |
| 일정 관리 | 일정 CRUD, 변경 이력 | 호스트 |
| 참석 집계 | RSVP(참석/불참/미정) 집계 | 참여자 |
| 알림 | 일정 변경/리마인더 발송 | 시스템 |

## 6. 성공 지표 (KPI)

> 아래 수치는 예시 목표값이다. 실제 OKR 확정 후 교체한다.

| 지표 | 정의 | 목표(예시) | 측정 방법 |
| --- | --- | --- | --- |
| 활성 모임 수 | 최근 30일 내 일정이 1개 이상 있는 모임 | 출시 3개월 내 **500개** | DB 집계 배치 |
| 초대 전환율 | 초대코드 발급 대비 실제 참여 비율 | **60% 이상** | 이벤트 로그 |
| 일정 응답률 | 일정 1건당 RSVP 응답 비율 | **70% 이상** | RSVP 테이블 |
| 알림 도달률 | 발송 대비 성공 수신 비율 | **95% 이상** | 알림 발송 로그 |
| p95 응답시간 | 핵심 API p95 지연 | **300ms 이하** | [observability](../architecture/observability.md) |
