# Project Brief

> 이 문서는 Kohere 프로젝트의 Project Brief다. **MVP 기획 메모**와 **요구사항 정의서**(`docs/requirements/요구사항 정의서 .xlsx`, 2026-06-15 기준)를 반영했다. 요구사항 정의서에도 명시되지 않은 항목은 `(입력 필요)`, 추론으로 채운 항목은 `(확인 필요)`로 표시했다.

## 목적

이 문서는 **외국인 맞춤 주거 유형 탐색 서비스**(Kohere)의 목적·배경·범위·핵심 기능·KPI·마일스톤을 한 곳에 정리해, 합류한 팀원이 프로젝트 맥락을 빠르게 파악하도록 한다. 화면·기능의 상세 명세는 [요구사항 정의서](../requirements/요구사항%20정의서%20.xlsx)를 정본으로 한다.

## 1. 한 줄 요약 (Elevator Pitch)

한국의 주거 형태(고시원·코리빙·쉐어하우스 등)와 부동산 용어를 모르는 **외국인**이, 5단계 진단(지역·입국 목적·주거 환경 조건·예산·ARC 보유 여부)에 답하는 것만으로 **자신에게 맞는 매물을 추천받고(지도 + 리스트), 임대인과 인앱으로 연결**되는 모바일 서비스.

## 2. 배경 (Background / Problem)

### 문제

- 외국인은 한국의 주거 형태 차이(고시원 / 코리빙 / 쉐어하우스 등)와 예산별 선택지를 알기 어렵다.
- 복잡한 한국 부동산 용어가 진입장벽이 되어, 자신의 조건(입국 목적·예산·ARC(외국인등록증) 발급 여부·생활 조건)에 맞는 집을 찾기 힘들다.

### 타겟

고시원 / 코리빙 / 쉐어하우스 등 한국의 주거 형태 차이를 모르고 예산별 선택지를 고민하는 외국인.

### 대표 상황 (페르소나)

1. 입국 1~2개월 전, 해외에서 미리 방을 알아보는 외국인
2. 기숙사에서 주거 변경을 희망하며 임시 거처를 구하는 외국인
3. 이사를 앞둔 외국인

## 3. 목표 (Goals)

### 핵심 가치 (정성 목표)

복잡한 한국 부동산 용어를 몰라도, 몇 가지 질문(지역·입국 목적·주거 환경 조건·예산·ARC)을 통해 자신에게 가장 알맞은 매물 리스트를 추천받을 수 있다.

> (입력 필요) 측정 가능한 목표가 MVP 기획 메모·요구사항 정의서 어디에도 명시되지 않았다. 다음을 정해야 한다.
>
> - 핵심 목표(예: "진단을 완료한 사용자의 N% 이상이 매물 상세 조회 / 신청·문의로 진행")
> - 정량 기준과 달성 시점

## 4. 범위 (Scope)

### In scope (MVP)

요구사항 정의서 기준, MVP는 아래 영역으로 구성된다. (매물 데이터는 **서울 지역 기준**)

| 영역           | 핵심 내용                                                                                                                                                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 인증 · 온보딩 | 소셜 로그인(Apple / Google), 온보딩 필수 정보(이름·성별·생년월일·국가번호·전화번호·비자 정보[유학·연수 / 취업 / 거주·가족동반 / 워킹홀리데이 / 관광 / 기타]), 이용약관·개인정보처리방침 동의, 소셜 로그인 실패 시 에러·재시도 처리                                    |
| 홈             | 검색·찜·알림 진입, "유형 진단 시작 / 재진단" 진입(진단 완료 여부로 문구 분기), 최근 본 매물(7일 내, 최대 5개), 하루 1개 퀴즈(정답 시 포인트 적립 로그), 생활 팁                                                                                                              |
| 맞춤 진단 챗봇 | 5단계 진단 — ① 지역(서울/부산/경기 선택지 노출,**MVP 데이터는 서울 기준**) ② 입국 목적(유학 / 유학 외, 다중 선택) ③ 주거 환경 조건(9개 중 최대 3개) ④ 월 예산(슬라이더) ⑤ ARC 발급 여부 → 결과: 매물 리스트(하단) + 지도(상단) 동시 노출, 0건 시 키워드 조정 제안 |
| 매물 탐색      | 지도 탭(학교명·지역명·지하철역 검색, 조건 필터 칩, 클러스터 마커, 지도:리스트 50:50, 추천/가격/거리순 정렬), 매물 상세(사진 갤러리·유형·가격·보증금·계약기간·위치·편의시설 태그·임대인 정보), 찜                                                                      |
| 임대인 연락    | 신청하기(입주 희망일 + 계약기간 1/3/6/12개월 → 예약 정보가 채팅방에 자동 전송) / 문의하기(임대인과 인앱 채팅방 생성) — 텍스트 메시지 송수신(이미지 불가)                                                                                                                     |
| 커뮤니티       | 자유게시판 · 동네생활(제목 + 본문 텍스트, 사진·동영상 제외), 좋아요·댓글·공유·신고, 키워드/해시태그 검색, 동네친구 1:1 채팅                                                                                                                                               |

> (작성 중) 더보기 탭(찜한 매물·내 게시글·주거 생활 가이드·알림 설정 등)은 요구사항 정의서에서 아직 작성 중이라 **MVP 포함 범위가 미확정**이다. 알림 설정(푸시 on/off 토글)도 정책 논의가 필요하다. `(입력 필요)`

### 주거 환경 조건 9종 (진단 3단계)

즉시 입주 / 여성 전용 / 개인 화장실 / 개인 욕실 / 영어 소통 가능 / 전입신고 가능 / 관리비 없음 / 식사 제공 / 2인실 (영문 라벨 병기)

### Out of scope / 고도화 (MVP 이후)

- 결제 시스템
- 서울 외 지역 매물 수집 (MVP 데이터는 서울 기준)
- 포인트 사용처·정책 (MVP는 적립 로그만 기록)
- 임대인 등록 페이지 제휴 또는 자체 생성 (매물 데이터 수급 방식)
- 매물별 리뷰 작성 (결과 정렬이 "리뷰 기반"이나 작성 방식 미정 — 초기엔 추천/가격/거리순 정렬로 제공)
- 메시지 비속어·외부 연락처 유도 필터링 (확정 X)
- 주거 형태 안내 가이드북 PDF 다운로드 (인앱 "주거 생활 가이드"로 제공, PDF 다운로드 제공 여부는 더보기 탭 작성 후 확정)

## 5. 핵심 기능 목록 (Key Features)

| 기능                          | 주요 액터           | 비고                                        |
| ----------------------------- | ------------------- | ------------------------------------------- |
| 소셜 로그인 · 온보딩         | 사용자(외국인)      | Apple / Google, 비자 정보 등 필수 정보 입력 |
| 맞춤 진단 & 매물 추천         | 사용자(외국인)      | 5단계 진단 → 매물 리스트 + 지도            |
| 매물 탐색 · 찜               | 사용자(외국인)      | 지도 탭 / 리스트 / 상세                     |
| 신청 · 문의 (인앱 채팅)      | 사용자 ↔ 임대인    | 예약 신청 / 문의 → 채팅방                  |
| 커뮤니티 (게시판 · 동네친구) | 사용자 ↔ 사용자    | 게시글·댓글·좋아요·공유 / 1:1 채팅       |
| 게이미피케이션                | 사용자(외국인)      | 일일 퀴즈 + 포인트 적립 로그                |
| 신고 처리                     | 운영 / 관리자(미정) | 게시글·댓글·메시지 신고                   |

> (입력 필요) 운영자 / 관리자 액터(신고 처리, 매물·게시글 관리)의 존재 여부·역할과 **임대인의 매물 등록 경로**는 요구사항 정의서에서 확정되지 않았다.
