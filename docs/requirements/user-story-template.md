# User Story & Acceptance Criteria Template

> 유저 스토리와 인수 조건(AC)을 일관 형식으로 작성하기 위한 템플릿입니다.
> 에러는 [error-response-guide](../api/error-response-guide.md)의 표준 코드/형식을 따릅니다.

## 유저 스토리 템플릿

```text
제목: [기능 요약]

As a   <역할/페르소나>
I want <원하는 기능/행동>
So that <얻고자 하는 가치/이유>
```

> (작성) ID·우선순위·추정·상태·관련 NFR 등 메타데이터를 함께 적는다.

## 인수 조건 템플릿 (Given / When / Then)

```text
시나리오: [무엇을 검증하는가]

Given <사전 조건/상태>
When  <사용자/시스템 행위>
Then  <관찰 가능한 기대 결과>
```

> (작성) 정상 / 검증 실패 / 인증·권한 / 경계·동시성 시나리오를 각각 추가한다.

## 체크리스트

> (작성) 스토리·AC가 갖춰야 할 항목을 적는다.
