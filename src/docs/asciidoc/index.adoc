테스트로 생성된 스니펫 기반 API 문서다(ADR-0007, Spring REST Docs). 모든 응답은 공통 래퍼 `{ success, data, error }`이며 시각은 ISO-8601 UTC다. 인증은 `Authorization: Bearer <accessToken>`.

== 소셜 로그인

`POST /api/v1/auth/social-login` — 공개. 소셜 `idToken`을 검증하고 신규/기존을 분기한다. 신규·온보딩 미완료는 온보딩 임시 토큰(`refreshToken` 없음, `onboardingRequired=true`)을, 기존 ACTIVE는 정식 access+refresh를 발급한다.

== 온보딩

`POST /api/v1/auth/onboarding` — 온보딩 스코프 토큰 필요. 필수 약관 동의·프로필을 확정해 PENDING→ACTIVE로 전이하고 정식 access+refresh를 발급한다. 약관 버전은 서버 설정값을 서버가 기록한다(ADR-0012).

== 토큰 재발급

`POST /api/v1/auth/reissue` — 공개(본문 refresh). 항상 회전한다 — 제출 refresh를 폐기(ROTATED)하고 새 access+refresh를 발급한다. 폐기 토큰 재제출(재사용)은 사용자 전체 토큰을 무효화하고 401을 반환한다(ADR-0006).
