# Review Pr

## 목적

Pull Request 변경사항을 품질, 테스트, 문서, 보안, 운영 리스크 관점에서 리뷰한다.

## 절차

요구사항 충족, 변경 범위, 테스트 누락, 문서 누락, 보안/운영 리스크를 리뷰한다.

## 출력 형식

```md
## 요약

## 변경/제안

## 테스트/검증

## 리스크

## 다음 액션
```
