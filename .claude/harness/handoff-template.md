# Handoff Template

> 세션/작업자 간 **인수인계** 양식이다. 작업을 넘길 때 아래 블록을 복사해 채운다.
> 인수받는 쪽이 맥락을 다시 파악하지 않고 바로 이어갈 수 있게 하는 것이 목적이다.

## 인수인계 블록 (복사해서 사용)

```markdown
## Handoff — <작업/기능명> (YYYY-MM-DD)

### Context
- <지금까지의 배경과 목표 — 왜 이 작업을 하는가>

### What changed
- <이번에 바꾼 것: 파일/동작/결정>

### What remains
- [ ] <남은 일과 현재 위치>

### Risks
- <주의할 점, 미해결 위험, 빠지기 쉬운 함정> (없으면 "없음")

### Suggested next prompt
- <다음 작업자가 바로 쓸 수 있는 시작 프롬프트 한 줄>
```
